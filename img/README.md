# Customer pictures

Put the pictures for your web tags in this folder (square or landscape, around 400 to 800 px wide, JPG, PNG or WebP,
ideally under 200 KB so they load fast on mobile data).

In the app, open a workflow, scroll to **Web tag > Page look**, and type the file name (for example `cafe.jpg`) in
**Picture**. The runner page shows it at the top, in place of the app tile.
